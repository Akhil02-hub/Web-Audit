# Outside In — Website Audit

Canonical website: https://outside.vercel.app/

Outside In checks a small sample of pages that are publicly accessible without signing in. It reviews availability, page metadata, basic accessibility signals, performance indicators, and common security headers, then returns findings with practical suggestions.

## Limits

- The scan is a point-in-time observation, not a penetration test or certification.
- It does not inspect private routes, accounts, analytics, application source code, or business logic.
- Browser-only checks such as Core Web Vitals, rendered contrast, keyboard behavior, and JavaScript-only interactions are not measured.
- A score summarizes the checks that ran; it does not prove security, compliance, or search ranking.
